04 / INSTALL

Up and running in three steps.

  1. 01

    Get Python

    Install Python 3.10 or newer. Tick "Add python.exe to PATH" during setup.

  2. 02

    Download and unzip

    Grab the zip, unzip it anywhere you like, such as Documents\DreadOS-AI.

    ⤓ Download JARVIS
  3. 03

    Launch

    Double-click Start-JARVIS.cmd, then open http://127.0.0.1:8765 in Chrome or Edge. Open Setup to pick your AI.

Optional: local voice (offline speech in and out) 
> cd DreadOS-AI
> python -m venv .venv-voice
> .venv-voice\Scripts\pip install -r requirements-voice.txt
> Start-DreadOS.cmd

After this, Start-DreadOS.cmd and Stop-DreadOS.cmd run JARVIS in the background with the Kokoro voice.

Optional: run AI fully offline

Install LM Studio, load a chat model and start its local server. In JARVIS Setup choose Local AI, enter http://127.0.0.1:1234/v1 and click Find local models.

05 / PRIVACY

Your machine. Your rules.

  • JARVIS runs on 127.0.0.1. Nothing is hosted in the cloud by us.
  • Chats, memory and settings stay in the data folder on your PC.
  • Messages go only to the AI provider you choose, or nowhere at all with a local model.
  • The microphone stays off until you click Talk. No wake word, no background listening.
  • Tools only run after you press Approve & run.
